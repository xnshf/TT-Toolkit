# 界面与入口

路径：**设置 / 界面与入口**。本页始终可访问，不需要启用开关，包含三项：唤起入口方式、外观主题、窗口与位置管理。

## 入口方式

- **悬浮球**：默认方式，可拖动，桌面与移动端分别记忆位置。
- **魔棒菜单**：在聊天输入框旁的扩展菜单添加 **TT-Toolkit**；隐藏悬浮球。
- **两者都显示**：同时保留悬浮球和魔棒菜单项。

三个选项以带图标、说明和金色选中态的原生单选卡片展示，不使用下拉框。宽内容区为三列，设置页可用宽度不超过 620px 时自动改为紧凑单列；桌面窄窗口与手机使用相同容器宽度规则。保存与重置按钮至少 44px 高，保留 Tab/方向键/空格及可见键盘焦点，手机两层导航不变。

“保存入口设置”和状态栏放在选项前方，并在入口选项区域内吸顶。状态区分“当前生效”“已选择但未保存”和“已保存、入口待恢复”，选择卡片不会立即写入；保存中锁定选择与重复操作。成功反馈 4.5 秒后消失，失败反馈保留到重试成功或主动关闭，布局重置不误报为入口保存。

选择后点击“保存入口设置”，立即生效，重启后保持；所有入口打开同一个 overlay/iframe 工作台。关闭工作台时焦点回到打开它的入口，魔棒方式回到宿主魔棒按钮。

## 窗口与位置

手机首次打开默认全屏，使用 CSS 四边 `inset` 贴合安全区内的可用空间，不再用 JS 写入计算后的全屏宽高；这不是隐藏系统栏的原生全屏接口。标题栏的“悬浮 / 全屏”按钮切换两种模式。顶部先避让宿主状态栏/摄像头安全区，再留出 12px 操作间距；全屏贴合屏幕边缘时标题栏再额外下移 16px（共 28px 间距），避免贴边误触；模式与关闭按钮保持 44px 触控目标。

悬浮窗口默认比上一版更窄，按住标题栏可上下、左右移动；拖动右下角手柄可放大/缩小，也支持聚焦手柄后用方向键调整。尺寸受可用区域与最小可操作尺寸约束，屏幕过小时仍优先不越界。缩放手柄位于独立布局行，不叠在内容上；底部“关闭工作台”栏已移除，只保留顶部关闭按钮。全屏不拖动、不显示缩放手柄，也不支持标题栏下拉关闭。

手机的模式、悬浮位置与尺寸自动保存，重启后恢复；切到全屏不清除悬浮位置和尺寸，取消拖动/缩放不保存中间状态。手机与桌面的工作台位置独立，桌面保留原有尺寸档位。宽度不超过 720px，或主指针为触控且高度不超过 720px 时使用手机外壳，覆盖常见手机横屏。

打开时先显示 overlay，再读取 iframe 和窗口的实际尺寸；旋转、分屏及宿主安全区变量变化后重新约束位置，不把临时约束后的坐标覆盖为新的记忆位置。保存失败不撤销当前可用布局，工作台显示持续警告及“重试保存布局”；仅记白名单 `warn`，不泄漏未知错误详情。

“重置界面布局”清除桌面和手机的工作台位置、恢复桌面标准尺寸与手机默认全屏，并将悬浮球移回默认位置；不改变入口方式、外观主题或其它功能设置。

## 外观主题

共 8 套，按“暗色在前、亮色在后”的顺序排成两行，宽内容区固定 4 列（每行 4 套），可用宽度不足 900px 时降为 2 列、不足 620px 时降为单列：

| 行 | 主题 | 调色板来源 |
| --- | --- | --- |
| 暗色 | 跟随宿主 | 宿主 `--SmartTheme*` 令牌实时桥接 |
| 暗色 | 青灰 | daisyUI `dim` |
| 暗色 | 午夜 | daisyUI `night` |
| 暗色 | 摩卡 | daisyUI `coffee` |
| 亮色 | 朝霞 | daisyUI `retro` |
| 亮色 | 樱雪 | daisyUI `cupcake` |
| 亮色 | 拿铁 | daisyUI `caramellatte` |
| 亮色 | 羊皮纸 | 手工调校（daisyUI 亮色主题底色均为中性白，无纸张感成员） |

**主题与入口方式的交互不同**：入口方式涉及挂载/卸载魔棒入口，有真实副作用，因此保留“草稿 + 前置吸顶保存栏”；主题是立即可见、可随时改回、无副作用的纯外观选项，所以**点选即应用并保存**，不进入草稿保存栏。保存失败时回退到原主题并给出保留到重试的提示；重新选择后不再显示上一次的取值回退提示。

“跟随宿主”会读取 TauriTavern 当前主题的文字色与强调色，并随宿主主题变化实时同步（无需重开）；iframe 不继承宿主的 `color-scheme`，因此工作台内的原生下拉框与滚动条明暗由宿主模糊底色的亮度推断。选择浅色主题时，工作台内的原生控件同步变为浅色。

色值出处、oklch 换算式与“为什么不能把强调色/状态色当正文”见 `docs/theme-provenance.md`；令牌层与宿主桥的结构见 `docs/architecture.md`。每套主题的六组文字/底色对比度（正文/画布、正文/面板、正文/卡片、正文/凹陷、强调按钮反白、危险按钮反白）由 `tests/theme.test.js` 锁定为不低于 AA 4.5:1。

## 失败与恢复

魔棒依赖宿主现有扩展菜单结构，不修改宿主源码。缺少菜单导出、节点或发现重复入口时只阻止本次入口切换，原入口仍可用。保存设置失败时也保留原入口，同时保留本次卡片选择供重试，清楚显示原生效方式；不重建控件或丢失焦点。

重启时若已选魔棒但菜单无法初始化，明确保留悬浮球作为恢复入口，不覆盖已保存的选择；悬浮球提示和本设置页说明原因与恢复步骤。失败按原因分流：**宿主实际加载到的 `extensions.js` 未提供魔棒导出**（`HOST_WAND_EXPORT_MISSING`）属于能力缺失，界面与恢复动作 `upgrade_or_replace_host_build` 都明确说明重载宿主无法恢复，只能升级或更换宿主构建（该导出由宿主提交 `00156ea7` 引入，分界是构建时间而不是版本号；若已在 2026-09-03 之后的构建上出现该原因码，应先实测该机加载到的脚本内容，不直接归因为构建过旧）；挂载点缺失、重复入口或设置写入失败属于可重试失败，保留原入口并引导重新保存或重载宿主。日志默认关闭，新增入口失败仅记录白名单 `warn` 事件 `system / shell / entry.failed`，包含操作、阶段、原因码、源码位置、字段、约束、实际类型/失败形态、结果、宿主 ABI 版本与恢复动作，不记录未知错误详情。`abiVersion` 只是宿主 ABI 版本常量，不能用来识别宿主构建，仅用于诊断收集。

设置使用 `tt-toolkit` / `main` / `shell-settings-v1`，`schemaVersion: 1`，保存 `entryMode`、`theme`、`launcher` 与 `workspace`。已知旧版 v1 缺少 `entryMode` / `theme` 时显式补齐 `floating` / `host`；缺少 `workspace.mobile` 时显式补齐 `{ mode: 'fullscreen', position: null, size: null }`，不继承桌面坐标；上一轮手机布局缺少 `size` 时显式补齐 null，已经存在但类型/数值非法时拒绝解析。**外观枚举取值无法识别时回退到安全默认并上报**（记白名单 `warn`、设置页给出提示），不再拒绝解析；**结构损坏（非对象、`schemaVersion` 不是 1、字段类型不对、布局坐标不是有限数值）仍显式报错**，不猜测。详见 `docs/storage-contract.md`。

开发期损坏外壳配置无法初始化时，可在宿主开发控制台明确删除这一个 key，然后重载（会清除外壳布局、最近路由、入口方式、外观主题与功能启用状态，不删除功能自身设置或日志）：

```js
await window.__TAURITAVERN__.api.extension.store.deleteJson({
    namespace: 'tt-toolkit',
    key: 'shell-settings-v1',
});
```

## 验证边界

宿主源码证据见 `docs/host-contract.md`。`tests/shell-layout.test.js` 只覆盖公开配置解析、尺寸补齐/损坏拒绝、模式及尺寸保留、手机/桌面隔离、唯一关闭入口及保存失败重试，不模拟浏览器几何，也不直接断言控制器字段或源码字符串。本轮临时 Chromium 检查打开实际“界面与入口”页，在 320×640、390×844、720×390、844×390 下验证四边安全区全屏、顶部操作间距、左右移动、可用空间内的上下移动、真实触控放大/缩小、最小/最大尺寸约束、缩放取消与重新初始化恢复；各尺寸下滚到页面末尾检查重置按钮完整可见且命中可点击。另验证方向键缩放、旋转不覆盖记忆、动态安全区、保存失败重试与 1280×900 桌面布局。临时浏览器脚本不作为新增持久化测试文件。`tests/toolkit-entry.test.js` 覆盖设置默认值/旧版补齐/非法值与结构损坏的分级、菜单初始化/缺失/重复、点击与键盘操作、监听清理、入口切换与保存失败、启动恢复和白名单日志。`tests/toolkit-settings-page.test.js` 覆盖单选卡片、保存前置、草稿/生效区分、处理中锁定、失败重试、提示生命周期、主题选择即保存与失败回退、布局重置与销毁。`tests/theme.test.js` 覆盖主题注册表契约、色板对比度与宿主桥不污染宿主。已通过 Chromium 使用实际 App/页面/样式检查：900px/720px 桌面工作台和 390px/320px 手机视口下无横向溢出，三列/单列降级、主题 4/2/1 列降级、吸顶保存、键盘方向键、触控选卡和保存正常。此浏览器检查不等同于宿主验收；真实宿主中菜单点击后的自动收起、跟随宿主的实时同步、Android/iOS WebView 真机位置、软键盘及刷新后的入口与主题恢复仍需人工验收。
