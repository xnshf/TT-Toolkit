# 世界书决策激活

“世界书 / 决策激活”以自然语言条件判断条目是否参与本轮宿主扫描，替代旧 AI 激活与一键填充描述。功能 ID 仍为 `world-info-ai`，首次安装默认关闭；“设置 / 模型服务”已注册，冲突检测仍隐藏。

## 配置与范围

- 在“设置 / 模型服务”保存用户自定义 URL、模型名和密钥，协议选择 **System One / Jev**。只要求协议兼容，不绑定供应商或模型名；旧 OpenAI Chat Completions 预设不能用于决策。
- 功能可跟随当前预设或指定一个 System One 预设。全局默认阈值为 `0.7`，按用户消息划分的最近轮数为 `3`，超时为 `10000` 毫秒；条目阈值为 `null` 时跟随全局，否则独立覆盖。概率 **≥ 阈值** 才通过。
- 每本世界书有接管开关，每条条目选择原生或接管，并填写非空自然语言条件；可批量切换模式、设置或清除阈值。草稿须明确保存，下轮生效。
- 普通常驻、向量、关键词条目均可配置接管。模板/EJS/ST-Prompt-Template 专用语法、`@@dont_activate` 和异常条目不接管；手动禁用、角色名/标签过滤、生成类型过滤仍尊重宿主原生资格。
- 自动判定只处理当前聊天实际挂载的全局、角色、聊天与 Persona 世界书。未接管且符合资格的常驻条目作为背景；未挂载的书不进入上下文。预算、分组竞争、顺序和注入位置仍由宿主处理，通过条件不等于最终注入。

## 发送内容与协议

上下文来自 canonical `chat[]` 的当前分支 `mes`，不读取 `.mes` DOM 或其它 swipe。排除隐藏/system/tool 消息，按最近用户轮次选择对话；swipe 不包含末尾旧回复，regenerate 使用宿主已经删除旧回复后的状态，continue 按宿主续写深度口径处理。`state` 包含 `background`、`dialogue` 和最新用户正文 `current_input`。

对话与原生常驻背景只调用宿主 **prompt 正则**（`isPrompt: true`，区分用户、AI、世界书来源及对话深度），不再次运行写入期正则，不执行 EJS，也不额外宏展开这些正文。条件单独通过严格 `substituteParams` 展开宏，存储仍保留原文；正则接口、宏接口缺失、抛错或返回非字符串时，不以未经处理的原文继续请求，而是本轮原生回退。

`kernel/decision-model.js` 直接 `fetch` System One 端点，发送 `{ model, state, questions }`；每个问题为 `{ type: "noul", instructions }`，回答须精确对应问题 ID，`type` 为 `noul`，概率为 `[0,1]` 内有限数值。响应 JSON 重复键、缺失/未知回答和非法概率均拒绝。可选 usage 只展示服务实际返回的安全 token 计数。

每次判定的全部缓存未命中问题合成 **一次 POST**，不重试、不降级到 Chat Completions、不隐式裁剪输入，也不假定通用模型 token 预算。发送内容包含所选对话、原生常驻背景正文和接管条件（问题 ID 含世界书名/UID）；接管条目正文不作为该条目的判定内容发送。开启自动判定可能产生费用。

## 生成生命周期与临时变更

`GENERATION_STARTED` 清理旧事务；`GENERATION_AFTER_COMMANDS` 仅登记支持的 normal/regenerate/swipe/continue 生成身份，不提前付费请求。dry-run、`skipWIAN`、离线或尚未进入具体成员请求的群聊 wrapper 不登记请求。真正判定延迟到 `WORLDINFO_ENTRIES_LOADED`，此时普通发送的用户消息已入列。

四组事件数组先经内核完整校验，再由末位监听器异步处理；申请末位不保证其它扩展后来不会重排。应用前后复验 stable ID、完整聊天 ref、生成角色 ID/头像、消息快照及目标条目；停止、结束、切换聊天和停用会取消或清理事务。非法事件、超时、网络/响应异常或过期结果不修改本轮数组，提示原生回退；下一轮重新校验。

变更仅发生在扫描局部条目副本：未通过的接管条目置 `disable: true`；通过的置 `constant: true`，关闭概率门，清除 sticky/cooldown/delay 与递归等待/排除门。不发送 `WORLDINFO_FORCE_ACTIVATE`，不改持久化触发字段、不绕过角色/标签/生成资格，不保证绕过预算或分组竞争。

**已接受限制**：宿主事件没有能证明调用来源的生成关联 ID。有效生成事务内，无法可靠区分正式扫描与其它扩展发起的世界书加载；后者可能提前触发付费判定或消费临时决策。身份守卫和末位监听不能消除此时机/激活歧义，不宣称请求一定只发生在最终正式扫描。

## 缓存、记录与手动测试

- 仅内存精确问题缓存：包含预设连接、协议标记、实际 state 与展开条件；容量 `500`，TTL `60` 秒。缓存概率不含阈值，改阈值可复用；下次判定发现 URL/模型/密钥/预设变化会清空，也可手动清除。停用清空缓存。
- 最近最多 `50` 条内存判定记录展示概率、阈值、请求数、缓存命中及服务实际 usage。生成记录的最终注入状态仅取非 dry-run、`isFinal` 的 `WORLDINFO_SCAN_DONE.activated.entries` **Map**；未获得该结果时标为未知，不把“通过”冒充“已注入”。记录不持久化，可手动清除。
- 可明确触发“测试已保存配置”或“测试本书未保存草稿”。均使用当前挂载范围，草稿仅替换所选且已挂载世界书的配置；发送前说明上下文/背景/条件、所选服务与可能费用并确认。测试可取消，只生成内存记录，不保存配置、不应用激活。没有自动 dry-run 或后台条件测试请求。

## 导入、保存与重置

配置导出不包含模型预设或密钥。导入格式 `tt-toolkit.world-info-decision.v1`，先预览按 UID 匹配的模式、条件和阈值，跳过未知 UID/不可接管条目；UID 相同不代表正文相同。明确应用后仅合并到当前草稿，不改变整书开关、不自动保存。

功能设置 key 仍为 `main/world-info-ai-settings-v1`，值为 schema 2；已知 v1 保留 `presetId` 并补齐新默认值。世界书字段仍为 `extensions["tt-toolkit"].worldInfoAiRouter`，schema 2 保存开关及 `{ mode, aiDescription, threshold }`；已知 v1 描述保留为条件、阈值迁移为 `null`。未知/损坏 schema 明确报错并提供对应重置，不猜测或静默覆盖。

保存前通过 fresh 读取比较整本世界书；变化则保留草稿并要求重读，不覆盖其它编辑。优先嵌入配置并后端往返验证；世界书写入本身失败直接报错（世界书未被改动，不降级成回退成功），只有写入成功但读回确认不到完整配置时才只把配置写入 `world-info-ai/world-<sha256>` 回退记录。现有回退在嵌入保存验证成功且清理完成前仍为权威；合法旧 ASCII key 可读取并在保存时清理。重置仅清除此书配置字段与对应回退，保留原生正文/其它扩展，不建立备份。详见 [存储契约](./storage-contract.md)。

## 验证边界

直接 WebView 请求可能受服务 CORS 限制；错误经脱敏处理并正常原生回退，不要求宿主代理、源码修改或专用宿主构建。密钥默认遮蔽，只存模型预设；日志仅记录原因码、阶段、白名单字段/类型与数量，不记录正文、条件、身份或未知错误详情。

协议、上下文、宿主适配、schema、路由、运行时与页面已有测试文件；本轮完整测试结果由最终验证记录确认。真实服务连通性、跨域、费用、角色/群聊生成时序、与其它扩展共存及世界书字段往返仍待实际 TauriTavern 验收，不宣称已实机通过。
