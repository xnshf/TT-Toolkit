# 聊天查看

聊天查看是“聊天数据”大类下的只读功能，稳定 ID 为 `chat-viewer`。首次安装默认关闭；停用时不读取聊天、不订阅事件，并释放内存快照。

## 楼层与显示

- 消息事实源始终是当前聊天的 canonical `chat[]`。
- “对话楼层”从 1 开始，纳入非明确 system/tool 的消息，按 `is_user` 区分用户或 AI；仅有 `is_system` 标记的隐藏消息与紧凑对话计入并标记。
- 已知 `extra.type`、`extra.uses_system_ui` 标记的系统楼层和 `role: 'tool'` / legacy `extra.tool_invocations` 标记的工具楼层不进入查看和正文搜索，但界面展示其排除数量。宿主也可能产生没有明确类型的系统消息，此时无法与隐藏的 AI 消息区分，按 AI 纳入。
- 每条同时展示宿主绝对索引，跳转时将 1 基对话楼层映射回该索引。
- 默认范围为最新 20 个对话楼层；起止范围为闭区间，列表按升序每页展示 20 条。
- 普通卡片展示正文开头 300 个字符，展开后展示完整的当前 `mes`。不展示 reasoning 或其它 swipes 的正文，只显示当前 swipe 序号与候选总数；候选信息异常时显示未知序号并警告，正文照常读取，不修复宿主数据。
- 非对象楼层或非字符串 `mes` 保留不可读占位，占据对话楼层位置并展示原始索引和具体原因；未知角色不猜测为 AI。该楼层不参与正文搜索，不能展开或跳转，其它消息仍正常使用；页面提示搜索结果可能不完整。

## 搜索与跳转

搜索独立于楼层范围，始终检查全部对话楼层的当前正文。匹配采用大小写不敏感的精确字面包含规则；结果按对话楼层升序分页。命中片段以首个命中为中心截取上下文，所有可见命中通过 iframe 内安全创建的 `<mark>` 元素高亮，不使用 `innerHTML`，也不改动 TauriTavern 正文。

跳转前会重新读取当前聊天。聊天 stable ID 或 ref（角色文件 / 群聊 ID）变化、目标编辑/删除或索引漂移会终止操作并要求重新选择；只在目标保持不变时，把宿主绝对索引交给 `/chat-jump`。宿主命令完成后工作台自动关闭。

## 状态与隐私

聊天切换、发送、接收、编辑、删除、更新和 swipe 事件会将现有快照标记为过期；下一次查看、搜索或跳转自动刷新，也可手动刷新。功能不把正文、搜索词或聊天副本写入 extension store、聊天 metadata 或脱敏日志；诊断日志可记录运行期聊天别名、安全楼层索引、数量、原因码、字段、类型、源码位置和处理/恢复动作。只读链路中的局部异常和可恢复拦截记录为 `warn`，界面显示警告，不禁用无关操作。
