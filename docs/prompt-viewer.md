# 提示词查看

提示词查看是“聊天数据”大类下的只读功能，稳定 ID 为 `prompt-viewer`。首次安装默认关闭；停用时不订阅事件、不读取组装结果，并释放内存快照。

它拆开宿主真实组装结果，按最终发送顺序逐条展示「最近一轮实际发送的提示词」，并能预测「给定输入会组装成什么提示词」。它不是第二套组装实现：上一轮直接读取宿主 PromptManager 的组装结果，预测直接调用宿主自身的 dry-run 组装路径。

## 接口范围

- 仅适用于聊天补全（Chat Completion）管线。Text Completion 管线不显示条目，并给出明确横幅。
- 只捕获正文聊天轮次：`normal`、`regenerate`、`swipe`、`continue`。其他扩展通过 `generateRaw` / `generateQuietPrompt` 发起的请求不会被捕获。
- 不读取最终的网络请求体，也不拦截请求。

## 上一轮

- 功能启用后在正文组装完成事件中更新快照，只保留最近一次；收到停止或结束通知不会自行生成快照。切换聊天、停止或进入新一轮后，尚未完成的旧捕获不会再发布。
- 条目按最终发送顺序排列，每条显示来源徽章、名称、role 与 token 数。来源包括预设、角色卡、Persona、世界书、对话历史、系统注入与未知。
- 世界书条目单独汇总在「本次激活的世界书条目」面板，显示条目 comment、位置/深度、世界书名与触发方式（常驻/关键词/向量）。`worldInfoBefore` / `worldInfoAfter` 条目会提示聚合了多少条世界书条目。
- 若宿主开启了 system 消息合并，逐条粒度会受限，界面给出警告；导出内容仍为实际发送结果。
- 世界书条目图片由本插件在组装事件内先插入发送数组，再由查看器按当次组装的消息位置补录。两个功能的启用先后不影响结果；发送与预测不会沿用上一轮图片。图片来源标为世界书，正文以 `[图片附件: image/png]` 占位，不会导出 base64 数据。
- 若某轮由 Agent 组装，其 Agent 专用条目会被移除，得到与普通组装一致的条目口径，并在界面注明移除数量。一轮生成内多次组装（工具调用或多轮 Agent 调用）时只展示最后一次，并注明组装次数。

## 预测

- 在“预测”标签输入假设的用户消息，点击“预测”，固定按普通聊天补全组装一次，结果与上一轮同构。
- 预测通过宿主自身的 dry-run 完成，会短暂占用宿主输入框并发出一轮 dry-run 事件，完成后立即还原输入框内容、选区与 token 统计。
- 预测只在宿主未生成且已完成收尾时可用；即使早退没有发结束事件，也能在宿主确认空闲后重新预测。停止动作不代表已收尾。失败时顶部显示原因并保留输入。

## 筛选、导出与隐私

- 可按来源类型筛选，并搜索条目正文或名称，命中在界面内安全高亮；搜索词不持久化。条目默认显示固定高度预览（约 5 行，超出裁切），可单条展开/收起，或使用“全部展开/全部折叠”；勾选“默认展开全部正文”后新快照直接全展开。搜索时会自动展开命中条目。
- 复制与下载的 `.txt` 只包含实际发送的 messages 数组，按 `[system]` / `[user]` / `[assistant]` 可读分块输出，不含插件标签；文件名为 `prompt-<sent|prediction>-<时间戳>.txt`。
- TXT 下载与日志文件、聊天文档共用 `host.exportFile()`，调用宿主保留前端接口 `utils.download(..., { throwOnFailure: true })`，不自行拼接 Blob 下载链接。按 delivered 布尔结果反馈完成/取消，不推测平台或保存位置；通知由宿主负责，插件不重复通知，仍保留页面反馈。写出失败记白名单 warn，明确取消记 info，插件日志不记录正文、文件名、路径或未知异常详情；维护者已接受宿主在接口失败时向 console 打印原始异常的副作用，宿主这部分输出不受插件脱敏保证。
- 唯一持久化是显示设置 `prompt-viewer-settings-v1`（是否默认折叠）。快照、预测结果、搜索词、筛选与输入框内容只驻内存。
- 日志只记录条目数、来源类型计数、世界书条目数、token 总计、组装次数与稳定错误种类，不记录提示词正文、世界书名、uid、稳定聊天 ID 或模型原始响应。
