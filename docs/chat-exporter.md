# 聊天导出

聊天导出把当前聊天的消息正文整理为 Markdown 或纯文本文档。它不是原始聊天备份，不能恢复聊天，也不会修改或保存聊天副本。

## 消息范围

- 与聊天查看共用 canonical `chat[]` 投影和对话楼层编号，不扫描 `.mes` DOM。
- 与聊天查看保持同一范围：纳入按 `is_user` 区分的非明确 system/tool 消息，包括角色开场白、仅有 `is_system` 标记的隐藏消息和紧凑消息；明确的 system、`role: 'tool'` 和 legacy tool 标记仍排除。没有明确类型的真正系统消息无法与隐藏的 AI 消息区分，也可能按 AI 被导出。
- 每层只读取当前 `mes`。不读取 `extra.display_text`，不导出其它 swipes、reasoning、附件字段、时间戳、原始楼层号或 metadata。
- 默认范围为全部对话楼层，可截取连续范围，并可选择全部、仅 AI 或仅用户。
- 非对象楼层和非字符串正文保留不可读占位，不补造或转换正文；所选范围内的不可读消息在预览中列出楼层和原因，用户确认后允许跳过并导出其它消息。无法分类的占位即使使用角色过滤也显示跳过警告，不静默归类或隐藏。
- 范围外的异常不阻塞范围内正常消息；候选编号或数组异常只警告，继续导出当前 `mes`，无需确认丢失内容。明确 system/tool 的正常排除不是故障。所有输出均为空时提示调整范围或规则，不生成没有正文的文档。

## 非破坏性规则

AI 与用户分别选择“不处理”“正选提取”或“反选删除”。每个角色分别保存正选和反选规则列表，但一次只执行当前策略。

- 正选规则必须同时提供开始和结束标记。所有完整命中基于原正文计算，重叠区间合并，按原位置拼接标记内部文本。
- 反选规则与聊天清洗的字面删除语义一致，按列表顺序执行，允许双边、单开始和单结束标记。
- 匹配区分大小写、支持跨行、不解释嵌套。
- 可把聊天清洗的 AI/用户正文规则复制到导出反选列表；复制后相互独立，不复制 reasoning 或自动清洗设置。
- 正选未命中、未配对标记或处理后空正文会在预览中警告。用户确认后跳过无输出消息；最终没有消息时拒绝下载。

## 文档与安全

- Markdown 使用一级文档标题、连续的二级“消息 N”标题和纯 Markdown 角色引用标签；纯文本使用对应的文本结构。
- 正文处理结果不做 trim、标题降级、换行规范化或宏替换。匿名化只改变结构化角色标签，不搜索正文中的名称。
- 必须先预览才能下载。聊天、范围、格式、角色过滤、匿名化或规则变化都会使预览失效；下载前再次验证 stable ID、聊天 ref 和目标正文。风险确认绑定当前计划；确认期间计划变化、读取期间出现聊天事件或不可读楼层恢复正文时，要求重建预览，不沿用旧确认。
- 跳过内容的确认说明遗漏数量、不可读数量、导出文件可能不完整以及自行备份建议。用户可取消或确认继续；导出不修改原聊天，也不代替宿主备份。
- 文档通过统一的 `host.exportFile()` 调用宿主保留前端接口 `utils.download()`，不直接依赖平台导出实现。下载前的身份、目标正文和当前风险计划复验保持不变；复验失败不触发导出，正文不进入插件诊断日志。当前宿主以 delivered 布尔值表示完成/取消，插件不推测平台或保存位置；异常记 warn，明确取消记 info，不自动重试。页面保留反馈，系统交付和通知由宿主管理，插件不重复通知。维护者已接受该接口失败时向宿主 console 打印原始异常的副作用；插件无法保证宿主这部分输出脱敏。
- 保存操作位于预览列表之前；每条长正文预览限制高度并在卡片内滚动，避免把关键操作推离当前任务区域。
- 设置保存在扩展级存储中；标题、范围、预览、聊天身份和正文不持久化。日志不记录标题、名称、正文或规则文本；默认脱敏模式保留具体原因码、源码位置、字段/约束/类型、异常楼层、处理结果和恢复动作。局部降级、风险确认要求和可恢复操作失败使用 `warn`，已确认继续使用 `info`。
