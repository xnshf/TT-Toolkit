# TT-Toolkit 基础功能介绍与使用指南

TT-Toolkit 是专为 TauriTavern 设计的前端工具箱。目前提供三个基础聊天工具：**聊天查看、聊天清洗和聊天导出**。它们都围绕当前打开的聊天工作，但用途和对数据的影响不同。

| 功能 | 适合做什么 | 是否修改聊天 |
| --- | --- | --- |
| 聊天查看 | 浏览、搜索和定位当前聊天中的消息 | 否，只读 |
| 聊天清洗 | 按规则永久删除正文片段或原生 reasoning | **是，永久修改** |
| 聊天导出 | 将聊天整理为 Markdown 或纯文本文档 | 否，只生成文件 |

安装完成后，点击 TauriTavern 页面中的 **TT-Toolkit 悬浮入口**打开工作台，然后进入 **聊天数据**分类。三个功能首次安装时默认关闭，第一次使用需要先在对应页面右上角启用。

入口可在 **设置 → 界面与入口** 中改为 **魔棒菜单** 或 **两者都显示**。魔棒菜单是聊天输入框旁的扩展菜单，展开后点击 **TT-Toolkit** 即可打开同一工作台。魔棒入口需要宿主实际提供的扩展菜单初始化接口；若提示当前加载到的脚本未提供该接口，说明该宿主构建不包含此能力（该接口由宿主 2026-09-03 之后的构建引入），需升级或更换宿主构建，重载宿主不会恢复。

同一页面还可选择 **外观主题**（8 套，暗色在上、亮色在下），详见下文“外观主题”。

## 1. 聊天查看

聊天查看用于快速浏览当前聊天，适合在长对话中寻找某段内容或跳转到指定楼层。它是完全只读的，不会改动消息。

### 主要能力

- 按对话楼层范围浏览当前聊天。
- 搜索全部用户和 AI 消息，不受当前浏览范围限制。
- 展开消息卡片查看完整正文。
- 从搜索结果或消息卡片跳转到 TauriTavern 中的对应消息。
- 标记隐藏消息、紧凑消息和当前 swipe 信息。

### 快速使用

1. 打开 **聊天数据 → 聊天查看**，启用功能。
2. 点击刷新，读取当前聊天；默认显示最新 20 个对话楼层。
3. 输入起始和截止楼层，可以查看某一段连续对话。
4. 在搜索框中输入关键词，可以搜索整段聊天。
5. 找到目标消息后点击跳转，工作台会关闭，并回到聊天中的对应位置。

> 搜索采用不区分大小写的字面匹配。聊天发生编辑、删除、发送或切换后，旧结果会失效；再次查看或跳转时会自动刷新。

## 2. 聊天清洗

聊天清洗用于删除消息正文中的固定区段，也可以删除 TauriTavern 原生 reasoning。它适合清理思考标签、内部标记、模板残留或不希望长期保留的固定内容。

> **重要：聊天清洗会永久写回当前聊天。TT-Toolkit 不提供备份或撤销。清洗重要聊天前，请先自行备份。**

### 规则示例

如果希望删除下面整段内容：

```text
<think>
这里是不需要保留的内容
</think>
```

可以设置：

- 开始标记：`<think>`
- 结束标记：`</think>`

规则按列表顺序执行，区分大小写并支持跨行。只填写开始标记会从该标记删除到正文末尾；只填写结束标记会从正文开头删除到该标记，因此单边规则需要格外谨慎。

### 手动清洗

1. 打开 **聊天数据 → 聊天清洗**，启用功能。
2. 进入 **规则设置**，分别配置 AI 正文规则和用户正文规则；需要时启用“删除原生 reasoning”或“清除其它 swipes（仅保留当前候选）”。后者默认关闭，永久删除其它候选及其信息，适用于手动/自动清洗范围，不受正文规则开关影响。
3. 保存规则后回到 **手动清洗**。
4. 设置“分别保留最新消息”的数量。比如填写 `5`，会分别保留最新 5 条 AI 消息和最新 5 条用户消息；填写 `0` 表示扫描全部可处理历史。
5. 点击 **扫描并预览**，检查统计、警告和每一项正文变化。
6. 确认无误后点击 **永久提交清洗**，再完成危险操作确认。

清洗会先读回范围内的未加载历史候选。单个异常候选、reasoning 或读回失败不会阻塞其它可定位内容；警告列出楼层/候选与遗漏原因，确认前请逐条核对。未加载候选无法读回时不会清除候选数组，自动模式也会保留异常并在后续增量重试。

修改保留数量后，旧预览会立即失效，必须重新扫描才能提交。任何可能产生空 swipe 的结果都会触发额外确认。

### 自动清洗

1. 进入 **自动清洗**。
2. 开启“生成结束后自动增量清洗”。
3. 分别设置要保留的最新 AI 和用户消息数量。
4. 保存设置。

自动清洗只在新一轮生成结束后处理新增范围。首次启用或规则变化时会先建立基线，不会突然回扫并修改全部旧聊天。

## 3. 聊天导出

聊天导出用于把当前聊天整理为易于阅读和分享的 Markdown（`.md`）或纯文本（`.txt`）文档。导出过程不会修改聊天。

> 导出的文档不是原始聊天备份，不包含完整聊天结构、其它 swipes、reasoning、附件或 metadata，不能用于恢复聊天。

### 快速使用

1. 打开 **聊天数据 → 聊天导出**，启用功能。
2. 填写文档标题，选择 Markdown 或纯文本格式。
3. 选择导出全部消息、仅 AI 或仅用户；需要时开启匿名说话者。
4. 设置起始和截止对话楼层。
5. 点击 **生成导出预览**。
6. 检查最终消息数量、规则处理结果和警告。
7. 点击预览上方的 **保存文档**，由宿主完成导出。桌面提示已发起下载，请查看系统默认下载位置；安卓使用公共下载目录或系统文件选择器，iOS 使用系统分享面板。

### 可选的导出规则

AI 和用户可以分别选择一种处理方式：

- **不处理**：原样导出正文。
- **正选提取**：只保留成对标记内部的内容，开始和结束标记都必须填写。
- **反选删除**：删除标记及其内部内容，规则与聊天清洗相同。

还可以点击 **复制聊天清洗反选规则**，把现有清洗规则复制到导出功能中。复制后的规则相互独立，后续修改导出规则不会影响聊天清洗。

如果正选规则没有匹配、标记不完整或处理后正文为空，预览会显示警告，并可能跳过相关消息。必须确认预览后才能保存文档。

## 推荐使用顺序

面对重要或较长的聊天，可以采用下面的顺序：

1. 使用 **聊天查看**搜索并确认目标内容。
2. 如需保留副本，先使用 **聊天导出**生成阅读文档，并在 TauriTavern 中另外备份原始聊天。
3. 最后使用 **聊天清洗**扫描、核对预览并执行永久修改。

简单记忆：**查看用于找内容，导出用于留文档，清洗用于永久删除。**

## 外观主题

**设置 → 界面与入口** 提供 8 套外观主题，按“暗色在上、亮色在下”排成两行：

| 行 | 主题 | 观感 |
| --- | --- | --- |
| 暗色 | 跟随宿主 | 自动取用 TauriTavern 当前的文字色与强调色，随宿主主题实时变化 |
| 暗色 | 青灰 | 蓝灰底 + 柔绿，对比不刺眼 |
| 暗色 | 午夜 | 藏青底 + 亮蓝 |
| 暗色 | 摩卡 | 紫褐底 + 金棕，暗色里最偏暖 |
| 亮色 | 朝霞 | 暖奶油底 + 陶土粉 |
| 亮色 | 樱雪 | 粉白底 + 薄荷 |
| 亮色 | 拿铁 | 奶油底 + 黑色强调，对比干脆 |
| 亮色 | 羊皮纸 | 纸张感暖白底 + 暗金强调 |

**点选即生效并自动保存**，不需要再点保存按钮，可以随时改回。默认是“跟随宿主”。选择浅色主题时，工作台内的下拉框与滚动条也会同步变为浅色。

主题只影响工具箱界面的观感，**不改变聊天内容、不改变宿主自身的主题设置**。
