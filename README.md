# TT-Toolkit

TT-Toolkit 是一个只面向 [TauriTavern](https://github.com/Darkatse/TauriTavern) 的前端工具箱插件，用来集中处理聊天等数据域的辅助功能。

当前版本以 [`manifest.json`](./manifest.json) 中的 `version` 为准。

## 功能

### 聊天数据

- **聊天查看**：按对话楼层浏览当前聊天，支持范围分页、全文搜索和跳转。
- **聊天清洗**：按规则移除消息正文中的指定内容，以及 TauriTavern 原生 reasoning；可选择清除其它 swipes、仅保留当前候选，候选异常局部跳过并提示；可选的自动清洗在每次生成结束后增量处理新增消息，并分别保留最新的用户和 AI 消息。
- **聊天导出**：按范围将当前消息正文整理为 Markdown 或纯文本文档，支持角色过滤、匿名标签和非破坏性正选/反选规则。

### 提示词

- **提示词查看**：逐条查看最近一轮实际发送的提示词，并预测给定输入会组装成什么提示词。

### 世界书

- **世界书管理**：按来源选择世界书，检索、查看和编辑条目，支持自动保存与手动保存。

### 设置

- **界面与入口**：通过单选卡片选择悬浮球、魔棒菜单或两者，使用前置保存栏应用设置，支持桌面和手机布局。
- **外观主题**：共 8 套，设置页按“暗上亮下”排成两行——暗色为跟随宿主、青灰、午夜、摩卡，亮色为朝霞、樱雪、拿铁、羊皮纸；选择后立即生效并保存。除“跟随宿主”与“羊皮纸”外，调色板均取自 [daisyUI](https://daisyui.com/) 内置主题（MIT License, Copyright 2020 Pouya Saadeghi），色值由 oklch 精确换算；跟随宿主会取用 TauriTavern 当前的文字色与强调色，并随宿主主题变化实时同步。
- **日志**：查看、筛选和导出 TT-Toolkit 的结构化诊断日志。

### 暂时下架

- **AI 激活**、**冲突检测**和**模型服务**目前不注册到工具箱，因此不会显示、加载或启动后台运行时。
- 对应源码和已有持久化数据仍然保留，后续完成重做后可以逐项恢复。

## 安装

TT-Toolkit 仅支持 TauriTavern，不兼容原版 SillyTavern。

用 TauriTavern 的扩展安装器安装，操作方法见 [插件基础知识 → 怎样安装新插件](https://st-doc.pages.dev/extensions/basic/#install-extension)。

安装时在插件 URL 里填本仓库地址：

```text
https://github.com/xnshf/TT-Toolkit
```

分支和标签留空即可，默认安装主分支最新版。装好后在「管理拓展」里勾选 **TT-Toolkit**。

安装后，点击宿主页面中的 TT-Toolkit 悬浮入口即可打开工具箱。在 **设置 → 界面与入口** 中可切换为 **魔棒菜单** 或 **两者都显示**；保存后立即生效。魔棒入口位于聊天输入框旁的扩展菜单中，名称为 **TT-Toolkit**。

## 首次使用

- 世界书管理首次安装默认启用；聊天查看、聊天清洗、聊天导出、提示词查看和日志功能首次安装时默认关闭，需要在工具箱设置中手动启用。
- 关闭某项功能后，TT-Toolkit 不会继续为该功能读取聊天或订阅相关事件。

## 数据与隐私

- 聊天查看直接读取当前聊天，不建立长期聊天副本，也不保存搜索词或聊天索引。
- 聊天导出只在内存中生成预览和文档；持久化内容仅限格式、匿名化和规则等轻量设置，不保存标题、楼层范围、聊天身份或正文。
- 提示词查看只在内存中保存最近一轮的组装快照与预测结果，不持久化提示词正文、世界书名或聊天身份，日志不记录正文。
- 世界书管理将用户明确编辑的条目直接写入宿主世界书文件；草稿仅在内存，不写入扩展存储。
- 暂时下架不会删除此前保存的模型服务预设、AI 世界书设置或聊天级冲突检测数据；下架期间这些功能不会读取或使用这些数据。
- 日志功能默认关闭，启用后默认使用脱敏模式。

## 使用前请注意

聊天清洗是永久操作，插件不提供持久备份或撤销。执行清洗前请先在 TauriTavern 中自行备份重要聊天，并仔细检查预览结果。`is_system` 也用于隐藏普通消息；清洗、查看/搜索和导出只排除有明确系统类型或工具标记的楼层，因此没有明确类型的真实系统提示也可能被纳入。

TT-Toolkit 目前处于 `0.x` 单用户开发验证阶段，功能和设置格式仍可能调整。
