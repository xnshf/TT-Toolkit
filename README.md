# TT-Toolkit

TT-Toolkit 是一个只面向 [TauriTavern](https://github.com/Darkatse/TauriTavern) 的前端工具箱插件，用来集中处理聊天、世界书和模型服务相关的辅助功能。

当前版本：`0.3.0`

## 功能

### 聊天数据

- **聊天查看**：按对话楼层浏览当前聊天，支持范围分页、全文搜索和跳转。
- **聊天清洗**：按规则移除消息正文中的指定内容，以及 TauriTavern 原生 reasoning。
- **自动清洗**：在生成后增量处理新增消息，并保留最新的用户和 AI 消息。

### 世界书

- **AI 激活**：使用每个条目的独立描述判断本轮是否需要激活该条目。
- 支持为不同世界书和条目单独配置；不改变未接管世界书的原生行为。

### 设置

- **模型服务**：保存多组 OpenAI-compatible 模型服务预设，支持测试连接和获取模型列表。
- **日志**：查看、筛选和导出 TT-Toolkit 的结构化诊断日志。

## 安装

TT-Toolkit 仅支持 TauriTavern，不兼容原版 SillyTavern。

1. 从本仓库下载代码压缩包并解压。
2. 将解压后的目录命名为 `TT-Toolkit`。
3. 把整个目录放入 TauriTavern 的第三方扩展目录：

   ```text
   %APPDATA%\com.tauritavern.client\data\extensions\third-party\TT-Toolkit
   ```

   确认该目录的根部直接包含 `manifest.json`、`index.js`、`style.css` 和 `src` 目录。

4. 重启 TauriTavern。

安装后，点击宿主页面中的 TT-Toolkit 悬浮入口即可打开工具箱。

## 首次使用

- 聊天查看、聊天清洗、AI 世界书激活和日志功能首次安装时默认关闭，需要在工具箱设置中手动启用。
- 模型服务预设需要填写 API URL、模型名称和访问密钥；AI 世界书激活依赖已配置的模型服务。
- 关闭某项功能后，TT-Toolkit 不会继续为该功能读取聊天或订阅相关事件。

## 数据与隐私

- 聊天查看直接读取当前聊天，不建立长期聊天副本，也不保存搜索词或聊天索引。
- 模型服务预设可以保存 API URL、模型名称和访问密钥。访问密钥默认遮蔽，不写入日志、导出文件、聊天或聊天 metadata。
- AI 世界书激活只向模型发送条目的独立描述和有限的聊天上下文，不发送世界书正文；判定失败时会回退到宿主的原生激活流程。
- 日志功能默认关闭，启用后默认使用脱敏模式。

## 使用前请注意

聊天清洗是永久操作，插件不提供持久备份或撤销。执行清洗前请先在 TauriTavern 中自行备份重要聊天，并仔细检查预览结果。

TT-Toolkit 目前处于 `0.x` 单用户开发验证阶段，功能和设置格式仍可能调整。
